Primary public sources: [OpenAI release](https://openai.com/index/introducing-gpt-oss/), [GLM publisher card](https://huggingface.co/zai-org/GLM-4.7-Flash), [Qwen publisher card](https://huggingface.co/Qwen/Qwen3.5-9B), [Ollama constrained output documentation](https://docs.ollama.com/capabilities/structured-outputs), [Ollama thinking controls](https://docs.ollama.com/capabilities/thinking). Licence suitability here means permissive model terms support commercial experimentation with attribution; it is not a legal opinion. Publisher benchmark results are not proxy-notice accuracy measurements.

The machine is Apple M3 Max, 16 CPU cores, 64 GiB unified RAM; MPS is available, CUDA absent. Ollama 0.34.3 is running at literal loopback `127.0.0.1:11434`; installed llama.cpp binaries and LM Studio backends also exist, but the LM Studio HTTP server is inactive. Transformers/Laya are already installed. Project MLX-LM, llama-cpp-python, vLLM and Ollama Python clients are absent. The adapter uses Python's standard-library HTTP client, no additional dependency, no redirects or proxies and no external host.

Pinned experiment settings: `semantic_pipeline/llm-config.json`. Runtime 0.34.3; Metal on Apple GPU; configured context **16,384** (checkpoint metadata limit 202,752); max output 2,048; temperature 0; seed 42; thinking disabled for bounded extraction; retained native runtime/template metadata. Full manifest digest and runtime version are checked before each call, so a mutable tag cannot silently change the experiment. Ollama's model metadata reports template `{{ .Prompt }}`; the actual `/api/chat` request and returned metadata are persisted. The smoke request used an 8,192 context and completed in 11.4 seconds including ~10.6 seconds model load; it is not a latency benchmark.

The task prompt is versioned in `semantic_pipeline/prompt.txt`; a schema and prompt hash identify it. Native JSON-schema generation plus strict Pydantic validation constrain output. Identity-normalised substring checks quarantine invented evidence. There is no generated probability or confidence field. No tools or network are provided to the model. All inference requests are local. Hosted APIs are not a fallback option.

The initial prompt is based on business definitions and generic minimal contrasts, not edited after viewing challenge failures. Routing and any disagreement preference must be selected on the existing validation file, frozen, then evaluated. Temperature-zero GPU inference is not assumed bitwise deterministic: reload/repeat checks must be reported separately.
